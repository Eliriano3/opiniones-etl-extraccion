Flujo del proceso de extracción

Ejecución en paralelo, recolección de resultados y salida temporal por fuente

1. Inicio Worker Service .NET 8
2. Configuración appsettings y entorno
3. Extracción Tres fuentes en paralelo
4. Resultados Registros, errores y tiempos
5. Salida temporal JSON por fuente y manifiesto
6. Log y resumen ILogger / Serilog
7. Fin Proceso detenido
CSV CsvHelper, 500 registros
Base de datos ADO.NET, 200 registros
API REST HttpClient, 200 registros
Errores por fuente Se registran en el log y el proceso continua con las demas fuentes.
Paralelismo: las tres fuentes se ejecutan con Task.WhenAll.
Resultado: 900 registros, 0 errores, 321 ms.
Trazabilidad: cada fuente deja su archivo JSON y su entrada en el manifiesto.
Resiliencia: un fallo de una fuente no detiene a las otras.
